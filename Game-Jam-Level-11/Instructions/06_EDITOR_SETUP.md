# 06. Сборка игровых объектов в Unity Editor

В исходном репозитории Main.unity и основные префабы были пустыми заготовками. Теперь приложение разделено на две сцены: Menu.unity и Main.unity. Для их авторского заполнения добавлен Editor-инструмент:

**Game Jam → Build Last Flame MVP**

## Первый запуск

1. Открой проект в Unity **6000.0.83f1** и дождись окончания импорта и компиляции.
2. В верхнем меню Unity выбери **Game Jam → Build Last Flame MVP**.
3. Дождись сообщения об успешном создании. Инструмент создаст Menu.unity и Main.unity, назначит Menu первой сценой сборки и откроет её. Нажми Play из Menu.

Инструмент выполняется только в Unity Editor. Он сохраняет prefab assets, создаёт простые спрайты и материал 2D Lit, собирает отдельную Menu-сцену с UI_Menu, UI_StartPanel и UI_SettingsPanel, затем создаёт игровую Main-сцену, расставляет четыре точки топлива и четыре зоны укрытия, подключает ссылки в Inspector и назначает Menu первой сценой сборки. Существующие пути и GUID заготовок Player, PickupRoot, EnvironmentRoot, UI_HUD и UI_StartPanel сохраняются за счёт перезаписи prefab assets по тем же путям.

Создаются отдельные префабы UI_FlameMeter, UI_Timer, UI_WindWarning, UI_ResultPanel, UI_SettingsPanel и UI_Menu. В Menu-сцене UI_StartPanel содержит три кнопки сверху вниз: ИГРАТЬ, НАСТРОЙКИ, ВЫХОД. Панель настроек содержит ползунки SFX и музыки, проценты громкости и кнопку НАЗАД. В Main-сцене UI_HUD содержит только игровые индикаторы и экран результата.

## Переход между сценами

- Menu — первая сцена приложения и отдельный экран главного меню.
- ИГРАТЬ загружает сцену Main через SceneManager. При загрузке Main матч стартует автоматически.
- Retry на экране результата сбрасывает существующие игровые объекты и сразу перезапускает матч.
- В собранной игре ВЫХОД закрывает приложение. В Editor кнопка только пишет сообщение в Console.

## Управление

- **WASD / стрелки** — движение.
- **Space (удерживать)** — защита от порыва ветра; скорость снижается до 45%.

## Настройки звука

- Кнопка **НАСТРОЙКИ** в главном меню открывает отдельный экран.
- Ползунок **SFX** управляет громкостью AudioSource на заранее размещённых точках топлива.
- Ползунок **МУЗЫКА** сохраняет общую громкость музыки. Музыкальный AudioSource заранее размещён отдельно в MenuSystems и GameSystems/Audio; каждый использует сохранённое значение в своей сцене.
- Значения сохраняются через PlayerPrefs и восстанавливаются при следующем запуске.
- В исходном репозитории аудиоклипов нет. Чтобы услышать звук, добавь клипы в Inspector: SFX — в AudioSource префаба PickupRoot, музыку — в AudioSource `MenuSystems` в Menu и `GameSystems/Audio` в Main. Оба источника зациклены и начинают воспроизведение автоматически, когда им назначены клипы.
- В укрытии дополнительный урон от ветра отключается.

## Быстрая проверка после авторской сборки

- При старте приложения открывается отдельная сцена Menu с тремя кнопками: ИГРАТЬ, НАСТРОЙКИ, ВЫХОД.
- ИГРАТЬ загружает сцену Main; в Main меню отсутствует, матч начинается автоматически.
- НАСТРОЙКИ открывают панель с двумя ползунками; НАЗАД возвращает в главное меню.
- SFX и Music меняют громкость назначенных аудиоисточников и показывают проценты.
- Заголовок индикатора огня центрирован над полосой, а значение привязано к правому краю панели; оба текстовых поля имеют отступы от краёв.
- В собранной игре кнопка ВЫХОД закрывает приложение.
- Сцена Menu стоит первой в Build Settings; Main идёт второй.
- В Main нет экземпляров UI_StartPanel/UI_SettingsPanel; они находятся только в Menu.
- Игрок перемещается и сталкивается с границами комнаты.
- При удержании Space включается визуал защиты и движение замедляется.
- Во время предупреждения появляется индикатор ветра; затем начинается порыв.
- В открытом пространстве порыв сильнее расходует огонь; защита снижает этот расход, укрытия убирают дополнительный урон полностью.
- Подбор топлива восстанавливает огонь; точка повторно активируется после cooldown.
- Радиус Light2D уменьшается вместе с запасом пламени.
- После 180 секунд появляется победный экран; при нуле огня — поражение.
- Retry сбрасывает существующие игровые объекты и немедленно запускает новый матч.

## Важное ограничение проверки

Editor-инструмент создаёт и сохраняет игровые объекты **до запуска игры**. Runtime-компоненты не создают игровые GameObject, UI, компоненты или эффекты; они только изменяют состояние существующих экземпляров.

В текущей среде Unity Editor не запускался, поэтому компиляция проекта, фактическая работа сцены и финальная сборка здесь не подтверждены. После запуска инструмента обязательно выполни быструю проверку выше в Unity. Повторный запуск полностью пересоздаёт обе сцены и основные prefab assets; сохрани ручные изменения перед запуском.
