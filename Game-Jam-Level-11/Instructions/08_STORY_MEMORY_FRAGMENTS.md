# Осколки памяти — Last Ember

## Содержание истории

Сюжет разделён на пять независимых записей в ScriptableObject StoryMemoryCatalog. У каждой записи есть стабильный ID, заголовок, короткий текст и символ.

1. **Тёплый мир** — «Когда-то ночью здесь никогда не было темно. В каждом окне горел свет».
2. **Последний шторм** — «Ветер пришёл без предупреждения. Мы пытались разбудить погасшие маяки — и выпустили его из самой Цепи».
3. **Смотритель** — «Он остался последним у старого очага. Он знал, что сам не переживёт ночь».
4. **Последняя искра** — «Он сохранил её не для себя. Последняя искра всё ещё отвечала на зов Цепи — и он верил, что однажды она зажжёт остальные огни».
5. **Секрет маяка** — «Маяк не создаёт огонь. Он только помогает тем, кто ещё горит, найти друг друга. И где-то далеко ей уже ответили».

Первые записи показывают мир до катастрофы, намекают на происхождение Серого Ветра и раскрывают решение Смотрителя. Последняя оставляет крючок для финала: искра не последняя, и на зов Цепи кто-то отвечает.

Каталог можно расширять через Inspector: добавьте новую запись с уникальным ID, названием, текстом и символом. Runtime-система не требует изменений. Чтобы добавить физическую точку подбора для новой записи, назначьте StoryMemoryPickup и укажите ID, менеджер и, при необходимости, существующий FuelPickup.

## Настройка в Unity Editor

1. Откройте проект в Unity и дождитесь завершения компиляции.
2. Остановите Play Mode.
3. Выполните **Game Jam → Story Memory → Setup Story Memory Fragments**.
4. Инструмент создаст каталог Assets/Story/StoryMemoryCatalog.asset, короткий атмосферный AudioClip, prefab UI_StoryMemory.prefab, разместит UI в существующем Canvas, назначит ссылки менеджера и сохранит Main.unity.
5. Первые четыре записи будут связаны с FuelPoint_01–FuelPoint_04. Пятая точка StoryMemory_Shard_05 будет размещена отдельно в верхней части уровня и не будет давать топливо.

Setup Tool проверяет наличие GameManager, Canvas и четырёх существующих топливных точек. Повторный запуск обновляет ссылки и UI, использует существующий каталог и не добавляет повторные строки с теми же ID.

## Как работает подбор

- Для первых четырёх воспоминаний StoryMemoryPickup подписывается на событие FuelPickup.FuelCollected. Сюжет открывается только после того, как существующий FuelPickup действительно увеличил запас огня.
- Скрипт FuelPickup не меняется: количество топлива, задержка восстановления, collider, renderer и правила подбора остаются прежними.
- Обычные повторные подборы продолжают давать только топливо. Уже найденное воспоминание не воспроизводится второй раз.
- Пятый осколок — отдельный trigger-объект. Он открывает запись, но не взаимодействует с FlameMeter и не меняет запас топлива.
- Уведомление не ставит игру на паузу: fade/hold анимация использует unscaled time и не меняет Time.timeScale. Полупрозрачное затемнение не перехватывает ввод.
- Компактная карточка показывает символ, заголовок и текст. Небольшой звук создаётся Editor Tool как короткий мягкий тональный звон.

## Журнал и сохранение

Кнопка **ПАМЯТЬ** в правом нижнем углу открывает журнал. В нём найденные тексты можно перечитать; ненайденные места показываются как неизвестные.

Найденные ID сохраняются в Unity PlayerPrefs по ключу:

**LastEmber.StoryMemoryFragments.v1**

Запись выполняется сразу после каждого нового открытия через PlayerPrefs.Save(). Данные переживают перезапуск игры на той же машине и в том же пользовательском профиле.

Для сброса локального прогресса вне Play Mode выполните **Game Jam → Story Memory → Reset Story Memory Progress** и подтвердите действие.

## Проверка в Play Mode

1. Запустите сцену Main и начните игру.
2. Соберите топливо в FuelPoint_01. Убедитесь, что шкала топлива увеличилась и появилось «Тёплый мир».
3. Аналогично соберите FuelPoint_02, FuelPoint_03 и FuelPoint_04. По порядку появятся «Последний шторм», «Смотритель» и «Последняя искра».
4. Найдите и коснитесь отдельного светящегося символа StoryMemory_Shard_05 в верхней части уровня. Должен открыться «Секрет маяка»; запас топлива при этом не меняется.
5. Проверьте короткий звук, появление/исчезновение карточки и лёгкое затемнение. Персонаж должен продолжать двигаться, а FlameMeter и таймер — работать как прежде.
6. Откройте **ПАМЯТЬ** и проверьте, что все пять найденных записей доступны для чтения.
7. Перезапустите игру и снова откройте журнал: прогресс должен сохраниться, а собранные маркеры не должны появиться повторно.
8. Для повторного прохождения сбросьте прогресс через меню Editor Tool.

## Ограничение проверки

Скрипты, сериализованные ссылки и Git diff можно проверить статически, но Unity Editor, компиляция проекта, импорт prefab и Play Mode не запускаются в среде подготовки изменений. После выполнения Editor Tool необходимо пройти сценарий выше в локальном Unity Editor.
