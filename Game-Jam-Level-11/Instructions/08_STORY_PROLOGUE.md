# Сюжетное вступление Last Ember

## Сценарий

Одноразовый пролог «Когда погас последний свет» длительностью около 21 секунды. Он проигрывается поверх существующего Canvas prefab-а `UI_Menu` и содержит четыре последовательных сюжетных этапа:

1. Чёрный экран и холодный ветер.
2. Разрушенный пепельный город, пустые дома и погасшие костры.
3. Последняя живая искра и история Последнего Смотрителя.
4. Дальний древний маяк и финальная фраза: «Пока горит хотя бы одна искра — надежда не умерла».

По завершении истории игра ждёт явного действия игрока. После последнего этапа сразу запускается игровой раунд, без показа главного меню.

## Переход между сценами

- ЛКМ, **Пробел** или кнопка **«ПРОПУСТИТЬ»** пропускают только текущий сюжетный этап и переводят к следующему.
- Каждое отдельное нажатие продвигает ровно на один этап. Одно нажатие не может закрыть весь пролог.
- На финальном кадре следующее нажатие запускает игру.
- Короткая блокировка ввода при старте исключает случайное срабатывание кнопки, которой пользователь мог запустить Play Mode.
- Один клик мыши обрабатывается только в одном месте; кнопка не имеет второго параллельного обработчика `onClick`.

Просмотр или пропуск сохраняется в PlayerPrefs по ключу `LastEmber.PrologueViewed.v1`. При последующих запусках вступление не повторяется автоматически и сразу показывается существующее главное меню. Для повторной проверки используйте **Game Jam → Reset Story Prologue Playback**.

## Настройка в Unity

1. Откройте проект в Unity **6000.0.83f1** и дождитесь компиляции.
2. Остановите Play Mode.
3. Выполните **Game Jam → Setup Story Prologue**.
4. Дождитесь сообщения об успешной настройке. Команда обновляет только дочерний объект `StoryPrologue` внутри существующего `Assets/Prefabs/UI/UI_Menu.prefab`.
5. Запустите `Assets/Scenes/Main.unity`.

Редакторская команда создаёт WAV-файлы в `Assets/Audio/SFX`, UI-слои, частицы, кнопку и AudioSource через Unity Editor API. Повторный запуск пересобирает только `StoryPrologue`.

## Границы изменений

- Не меняются `GameManager`, `PlayerController`, `FlameMeter`, `WindController`, укрытия, расход топлива, управление, длительность матча и условия победы/поражения.
- Не создаются Canvas или EventSystem: используются существующие Canvas и GraphicRaycaster `UI_Menu`.
- Runtime не создаёт UI/GameObject: все элементы и ссылки создаются и сохраняются Editor Tool-ом.
