Рабочая документация для 24-часового Game Jam на тему **«Не дай погаснуть»**.

1. [01 — Концепция и игровой цикл](01_GAME_PITCH.md) — идея игры, основная механика, core loop, стартовый баланс и MVP.
2. [02 — Глобальные правила разработки](02_GLOBAL_RULES.md) — обязательные технические ограничения. Главное: ничего не создавать и не собирать в рантайме; все объекты и элементы UI заранее настраиваются отдельными префабами.

## Концепция в одном абзаце

Игрок управляет маленьким огоньком в тёмной комнате. Запас огня постоянно уменьшается, а вместе с ним сокращается радиус света. Нужно находить заранее размещённые точки топлива, переживать порывы ветра и выбирать между быстрым движением, медленной защитой и безопасным маршрутом через укрытия.

## Технологии и текущее состояние проекта

- Движок: Unity **6000.0.83f1**.
- Рендеринг: **2D URP**.
- Язык: C#.
- Ввод: Input System.
- Интерфейс: uGUI.
- Основная сцена: Assets/Scenes/Main.unity.

В репозитории уже есть несколько заготовок, но они ещё не образуют готовую игру:

- Скрипты: CoverZone.cs и WindController.cs.
- Префабы: Player.prefab, PickupRoot.prefab, EnvironmentRoot.prefab, UI_HUD.prefab и UI_StartPanel.prefab.
- UI_HUD сейчас содержит Canvas, CanvasScaler и GraphicRaycaster, но ещё не собранный HUD.
- UI_StartPanel пока является визуальной заготовкой панели.

Не считать наличие этих файлов признаком готовой игровой логики. Перед реализацией проверять реальные компоненты и ссылки в Inspector. Существующие заготовки развивать, а не создавать параллельные дубликаты без необходимости.

## Главный приоритет

Сначала довести до приятного состояния один короткий цикл:

**увидеть топливо → выбрать маршрут → пережить порыв ветра → собрать топливо → сохранить огонь → повторить.**

Защита должна иметь понятную цену: во время удержания кнопки игрок движется медленнее. Укрытия позволяют переждать ветер, не теряя темп. Топливо даёт заметное восстановление света.

Одна хорошо отполированная механика важнее большого количества контента. Не добавлять новые системы, пока основной цикл не работает, не читается визуально и не приносит удовольствие.

## Ограничение по времени

На разработку есть **24 часа**. К 12-му часу должна существовать полностью проходимая версия от Start до Won/Lost и Retry. После 18-го часа не добавлять новые механики. Последние два часа оставить на финальную сборку и проверку.
