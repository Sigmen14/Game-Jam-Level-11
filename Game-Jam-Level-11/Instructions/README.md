# Инструкции Game Jam — «Последний огонёк»

Это рабочая документация для 24-часового джема на тему **«Не дай погаснуть»**.

## С чего начать

1. [01 — Концепция и игровой цикл](01_GAME_PITCH.md) — что за игра, в чём удовольствие и какая механика главная.
2. [02 — Глобальные правила разработки](02_GLOBAL_RULES.md) — обязательные технические ограничения, в первую очередь запрет на создание объектов и интерфейса в рантайме.
3. [03 — План реализации в Unity](03_IMPLEMENTATION.md) — сцена, префабы, ссылки в Inspector и минимальная архитектура.
4. [04 — План на 24 часа](04_24H_PLAN.md) — приоритеты, этапы и то, что нужно вырезать первым.

## Контекст проекта

- Движок: Unity **6000.0.83f1**.
- Рендеринг: **2D URP**.
- В проекте уже подключены Input System и uGUI.
- На момент подготовки инструкций в Assets есть стартовая сцена с Main Camera и Global Light 2D; игровых скриптов и готовых игровых префабов пока нет.

## Главный приоритет

Сначала довести до приятного состояния один короткий цикл:

**увидеть топливо → добежать → пережить порыв ветра → собрать топливо → сохранить огонь → повторить.**

Одна хорошо отполированная механика важнее большого количества контента. Не добавлять новые системы, пока этот цикл не работает, не читается визуально и не приносит удовольствие.
