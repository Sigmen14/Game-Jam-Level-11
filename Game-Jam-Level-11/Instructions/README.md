# Инструкции Game Jam — «Последний огонёк»

Рабочая документация для 24-часового Game Jam на тему **«Не дай погаснуть»**.

## С чего начать

1. [01 — Концепция и игровой цикл](01_GAME_PITCH.md) — идея игры, основная механика, core loop, стартовый баланс и MVP.
2. [02 — Глобальные правила разработки](02_GLOBAL_RULES.md) — обязательные технические ограничения. Главное: ничего не создавать и не собирать в рантайме; все объекты и элементы UI заранее настраиваются отдельными префабами.
3. [03 — План реализации в Unity](03_IMPLEMENTATION.md) — структура сцены, существующие заготовки, компоненты, ссылки в Inspector и порядок реализации.
4. [04 — План на 24 часа](04_24H_PLAN.md) — этапы, контрольные точки и приоритеты.
5. [05 — Контракты префабов](05_PREFAB_CONTRACTS.md) — какие префабы нужны, что каждый из них содержит и какие параметры должны быть доступны в Inspector.
6. [08 — Осколки памяти](08_STORY_MEMORY_FRAGMENTS.md) — сюжетная система, пять воспоминаний, журнал, сохранение и настройка через Editor Tool.
